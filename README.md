## 安装

1. 在 **Releases** 页面下载 `StevePlayer-Setup-2.0.1.exe`。
2. 双击运行，按安装向导提示完成安装（安装程序会先结束正在运行的 Steve Player 进程）。
3. 卸载：使用开始菜单中的卸载入口，或安装目录下的 `uninstall.exe`。
